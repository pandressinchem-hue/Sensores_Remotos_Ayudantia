# Sensores Remotos - Ayudantía de Cátedra

Repositorio de apoyo para la ayudantía de cátedra de **Sensores Remotos** (Ingeniería Ambiental, Universidad de Cuenca). Aquí se documentan las actividades, prácticas y controles de lectura realizados durante el semestre.

## Estructura del repositorio

```
├── guias/         # Guías de actividad y formatos de reporte (.docx)
├── practicas/     # Prácticas de Google Earth Engine / Colab exportadas como .html
└── .github/
    └── ISSUE_TEMPLATE/
        └── control_lectura.yml   # Formulario de control de lectura
```

## Control de lectura

Cada estudiante documenta su control de lectura abriendo un **nuevo Issue** en este repositorio:

1. Ir a la pestaña **Issues**.
2. Clic en **New issue**.
3. Elegir la plantilla **Control de lectura**.
4. Completar el formulario y enviarlo.

Cada Issue queda registrado con fecha, autor y contenido, sirviendo como evidencia del trabajo realizado en cada sesión.

## Prácticas

Las prácticas de Google Earth Engine y Google Colab se exportan como archivos `.html` autocontenidos y se suben a la carpeta `practicas/`. Si se activa GitHub Pages sobre la rama `main` (carpeta raíz o `/docs`), cada práctica queda accesible como una página web pública.
