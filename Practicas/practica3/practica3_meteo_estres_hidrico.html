Práctica 3 — Variables meteorológicas y estrés hídrico

Primero se verifican las fuentes de datos (CHIRPS, ERA5-Land, TerraClimate y MODIS), luego se construye un climograma y, al final, se analiza el estrés hídrico de una cuenca con el CWSI.

Objetivos Fuentes Conceptos Preparación Etapas Cuidados Entrega

1Objetivos de la práctica

  • Verificar datos meteorológicos de varias fuentes gratuitas antes de usarlos: unidades, escala y coincidencia entre ellas.
  • Construir e interpretar un climograma de una cuenca.
  • Calcular indicadores de estrés hídrico (P/PET, CWSI y déficit climático) y mapear el CWSI con MODIS.
  • Practicar histogramas, gráficos de series y estadísticas por región en Google Earth Engine.
Idea central: un dato satelital o de reanálisis no es una medición directa. Antes de interpretarlo hay que saber qué es, en qué unidades viene y cuánto se parece a otras fuentes.

3Conceptos clave

Climograma

Gráfico del promedio mensual de precipitación (barras) y temperatura (línea) a lo largo del año. Permite ver el régimen de lluvias y las épocas secas de un solo vistazo.

ET y PET

ET (real): agua que realmente se evapora y transpira.
PET (potencial): la que se evaporaría si hubiera agua suficiente. La diferencia entre ambas indica falta de agua.

CWSI

CWSI = 1 − ET / PET

0: la planta evapora lo que la atmósfera demanda (sin estrés). 1: casi no evapora pese a la demanda (estrés máximo).

P/PET y déficit

P/PET menor a 1 significa que la atmósfera demanda más agua de la que llueve. El déficit de TerraClimate es PET − AET, en mm: cuánta agua faltó para cubrir la demanda.

Ojo con el nombre: aquí se usa la forma teórica 1 − ET/PET calculada con productos satelitales. No es el CWSI empírico basado en la temperatura del dosel (Jackson et al., 1981), que lleva el mismo nombre. En el reporte indiquen cuál usan.

ETAPA 1Cuenca y fuentes de datos

Se define la cuenca y el periodo, se cargan las cuatro fuentes y se llevan a las mismas unidades. Si esta etapa tiene un error de unidades, todo lo demás estará mal aunque el código corra.

// ===== PASO 0 · CONFIGURACIÓN DE LA CUENCA Y DEL PERIODO =====
var punto = ee.Geometry.Point([-79.00, -2.90]);   // un punto dentro de la cuenca de estudio
var ROI = ee.FeatureCollection('WWF/HydroSHEDS/v1/Basins/hybas_8').filterBounds(punto);
var roiGeom = ROI.geometry();

var ANIO_INI = 2001;
var ANIO_FIN = 2023;      // periodo común a todas las fuentes
var ESCALA   = 5000;      // m, para las estadísticas regionales
var SECO_INI = 7;         // meses secos: se ajustarán tras ver el climograma
var SECO_FIN = 9;
var CLASE_LC = 12;        // clase IGBP para enmascarar (12 = cultivos); null = sin máscara

var anios = ee.List.sequence(ANIO_INI, ANIO_FIN);
var meses = ee.List.sequence(1, 12);
var fIni  = ee.Date.fromYMD(ANIO_INI, 1, 1);
var fFin  = ee.Date.fromYMD(ANIO_FIN, 12, 31);

Map.centerObject(roiGeom, 9);
Map.addLayer(ROI.style({color: '000000', fillColor: '00000000'}), {}, 'Cuenca (ROI)');
Map.addLayer(punto, {color: 'red'}, 'Punto de referencia');

// ===== PASO 1 · CARGAR LAS FUENTES Y UNIFICAR UNIDADES =====
// Unidades finales: P, ET y PET en mm/mes; T en °C

// ---- CHIRPS (diario, mm/día, ~5 km) -> suma mensual
var chirps = ee.ImageCollection('UCSB-CHG/CHIRPS/DAILY').select('precipitation');
var chirpsM = ee.ImageCollection.fromImages(
  anios.map(function (y) {
    return meses.map(function (m) {
      var ini = ee.Date.fromYMD(y, m, 1);
      return chirps.filterDate(ini, ini.advance(1, 'month')).sum()
                   .rename('P_chirps')
                   .set({'system:time_start': ini.millis(), 'year': y, 'month': m});
    });
  }).flatten()
);

// ---- ERA5-Land mensual (~11 km). Precipitación en METROS, temperatura en KELVIN,
//      evaporación con signo NEGATIVO
var era5 = ee.ImageCollection('ECMWF/ERA5_LAND/MONTHLY_AGGR')
  .filterDate(fIni, fFin.advance(1, 'day'))
  .map(function (img) {
    // COMPLETAR: metros -> mm (factor) y kelvin -> °C (valor a restar)
    var P   = img.select('total_precipitation_sum').multiply(____).rename('P_era5');
    var T   = img.select('temperature_2m').subtract(____).rename('T_era5');
    var ET  = img.select('total_evaporation_sum').multiply(-1000).rename('ET_era5');
    var PET = img.select('potential_evaporation_sum').multiply(-1000).rename('PET_era5');
    return ee.Image.cat([P, T, ET, PET]).copyProperties(img, ['system:time_start']);
  });

// ---- TerraClimate mensual (~4.6 km). Las bandas vienen con factor de escala
var tc = ee.ImageCollection('IDAHO_EPSCOR/TERRACLIMATE')
  .filterDate(fIni, fFin.advance(1, 'day'))
  .map(function (img) {
    var P   = img.select('pr').rename('P_tc');                           // mm
    var T   = img.select('tmmx').add(img.select('tmmn'))
                 .multiply(0.1).divide(2).rename('T_tc');                 // °C (media de tmax y tmin)
    // COMPLETAR: factor de escala de TerraClimate para aet (igual al de pet y def)
    var ET  = img.select('aet').multiply(____).rename('ET_tc');
    var PET = img.select('pet').multiply(0.1).rename('PET_tc');
    var DEF = img.select('def').multiply(0.1).rename('DEF_tc');          // PET - AET
    return ee.Image.cat([P, T, ET, PET, DEF]).copyProperties(img, ['system:time_start']);
  });

// ---- MODIS MOD16A2GF (500 m, cada 8 días, mm por 8 días)
var mod16 = ee.ImageCollection('MODIS/061/MOD16A2GF')
  .filterDate(fIni, fFin.advance(1, 'day'))
  .select(['ET', 'PET'])
  .map(function (img) {
    var valido = img.select('ET').lte(32700);          // los valores de relleno superan 32700
    // COMPLETAR: factor de escala de MOD16
    return img.updateMask(valido).multiply(____)
              .copyProperties(img, ['system:time_start']);
  });

// MODIS a mensual: promedio de los compuestos del mes x días del mes
var modisM = ee.ImageCollection.fromImages(
  anios.map(function (y) {
    return meses.map(function (m) {
      var ini  = ee.Date.fromYMD(y, m, 1);
      var fin  = ini.advance(1, 'month');
      var dias = fin.difference(ini, 'day');
      var prom = mod16.filterDate(ini, fin).mean();
      return prom.multiply(dias.divide(8)).toFloat()
                 .rename(['ET_modis', 'PET_modis'])
                 .set({'system:time_start': ini.millis(), 'year': y, 'month': m});
    });
  }).flatten()
);

print('Meses CHIRPS (esperado ' + (ANIO_FIN - ANIO_INI + 1) * 12 + '):', chirpsM.size());
print('Meses ERA5-Land:', era5.size());
print('Meses TerraClimate:', tc.size());
print('Compuestos MODIS de 8 días:', mod16.size());

function climMes(col, banda, m) {
  var img = col.filter(ee.Filter.calendarRange(m, m, 'month')).select(banda).mean();
  return ee.Number(img.reduceRegion({
    reducer: ee.Reducer.mean(), geometry: roiGeom,
    scale: ESCALA, bestEffort: true, maxPixels: 1e9
  }).get(banda));
}

var climatologia = ee.FeatureCollection(meses.map(function (m) {
  m = ee.Number(m);
  return ee.Feature(null, {
    mes:       m,
    P_chirps:  climMes(chirpsM, 'P_chirps', m),
    P_era5:    climMes(era5, 'P_era5', m),

// r = correlación de Pearson entre los 12 valores; luego, diferencia del total anual
function comparar(etiqueta, a, b) {
  var r  = climatologia.reduceColumns(ee.Reducer.pearsonsCorrelation(), [a, b]).get('correlation');
  var sa = climatologia.aggregate_sum(a);
  var sb = climatologia.aggregate_sum(b);
  var res = {};
  res['r (correlación)'] = r;
  res['Total anual ' + a] = sa;
  res['Total anual ' + b] = sb;
  res['Diferencia (a - b), mm/año'] = ee.Number(sa).subtract(sb);
  res['Diferencia relativa, %'] = ee.Number(sa).subtract(sb).divide(sb).multiply(100);
  print(etiqueta, res);
}

// ===== PASO 7 · ÍNDICES DE ESTRÉS HÍDRICO MENSUALES =====
var estres = climatologia.map(function (f) {
  var P   = ee.Number(f.get(BANDA_P));
  var pet = ee.Number(f.get('PET_tc'));
  var et  = ee.Number(f.get('ET_tc'));
  return f.set({

    // COMPLETAR: CWSI = 1 - ET / PET (denominador)
    'CWSI_tc': ee.Number(1).subtract(et.divide(____)),
    'CWSI_modis': ee.Number(1).subtract(
        ee.Number(f.get('ET_modis')).divide(ee.Number(f.get('PET_modis'))))
  });
});

6Cuidados al interpretar

  • Relieve y nubosidad: en los Andes ambos afectan la calidad de CHIRPS y de MODIS. Un píxel de 5 o 11 km promedia valles y cumbres a la vez.
  • MODIS mensual aproximado: ET y PET de MOD16 vienen cada 8 días; el valor mensual se estima como promedio de los compuestos por los días del mes. No es una cifra exacta.
  • Ninguna fuente es la verdad: la mejor verificación sería contrastar con una estación meteorológica local. Si disponen de datos de una estación cercana, úsenlos como reto.
  • Pocos píxeles: al enmascarar por cobertura, una clase pequeña puede dejar solo unos cuantos píxeles de 500 m; el histograma no será representativo.
Valores de referencia (corrida con el punto [-79.00, -2.90] y el periodo 2001-2023): la precipitación anual de TerraClimate en la cuenca va de unos 690 mm (año más seco) a unos 1 470 mm (año más húmedo); el CWSI mensual de MODIS va de aproximadamente 0,2 a 0,5, con máximos en agosto y septiembre. Úsenlos solo para comprobar que sus resultados tienen el orden de magnitud correcto.
